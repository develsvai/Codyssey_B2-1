# 결정

- 기존 12번째 Task에서 작성한 평가 답변 문서의 후속 개정이므로 같은 콘솔 용돈 기입장 Job에 두었다. 새 저장소 구현을 시작하는 작업은 아니다.
- 사용자가 요청한 방향에 맞춰 문서형 NoSQL을 검토 대상으로 설명했다. 특정 DB 채택을 확정하거나 실제 도입 권한으로 확대하지 않았다.
- 제너레이터는 한 건씩 전달하는 수단이며 소비자가 전체를 모으지 않아야 메모리 이점이 있다는 점을 설명했다. 파일 전체 읽기 비용과 메모리 점유량을 구분했다.
- NoSQL의 모든 제품에 동일한 기능이 있다고 일반화하지 않고 MongoDB를 공식 근거가 있는 예시로 사용했다. 인덱스 유지 비용, 집계 비용, 데이터 이관 및 import 전체 취소 정책의 보존도 함께 설명했다.
- 애플리케이션 코드와 다른 평가 항목을 유지하고 4-2 범위만 수정했다.
