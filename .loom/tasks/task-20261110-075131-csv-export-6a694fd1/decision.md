# 결정

- 사용자의 구현 승인과 앞선 요구사항 점검을 근거로 기존 Job에 CSV export 보완 작업을 추가했다.
- 월과 날짜 범위는 우선순위 없이 AND로 결합한다. 각각 검증한 필터를 적용해 원래 잘못된 범위와 유효하지만 겹치지 않는 조건을 구분한다.
- 월과 함께 지정하더라도 날짜 범위는 시작일·종료일 모두 필요하다. 유효하지 않은 조건은 파일 쓰기 전에 거부한다.
- 조건 조합은 기능 서비스에 둔다. CLI는 인수와 출력, infrastructure는 CSV 및 파일 I/O를 담당하며 계층 간 하향 의존성을 유지한다.
- 거래 전체를 메모리에 적재하지 않고 기존 생성기와 공통 CSV 출력 경로를 재사용한다.
